# Doylestown Pickleball videos

The public video site for Doylestown Pickleball's "Drills + Games Explained" series.
Everything in this repo is served as a static website (GitHub Pages), intended for
videos.doylestownpickleball.com.

- `index.html` is the page.
- Each video has its own folder, for example `7-11-drill/`, holding the landscape
  video, the vertical cut and the thumbnail.
- `assets/` holds the logos and the PT Sans font files.

The animation source that produces the videos lives in the private
`doylestown-pickleball` repo.
